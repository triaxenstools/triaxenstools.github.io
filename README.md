# TriAxen's Tools: Speed Ladder

A fast, single-page Speed tier calculator for **Pokémon Champions (Regulation M-C)**. Enter your Pokémon's Speed stat and instantly see which Pokémon you outspeed.

## Features

- **Full Reg M-C roster**: every legal Pokémon, grouped by base Speed
- **Speed modifiers**: None, Choice Scarf, Tailwind, +1/+2 Speed, Paralyzed, Icy Wind / -1, Scarf + Tailwind, and Speed-doubling abilities
- **Multiple speed columns** for every Pokémon:
  - Max+ (32 Speed points, +Speed nature)
  - Max (32 Speed points, neutral nature)
  - No investment (0 Speed points, neutral nature)
  - Min (0 Speed points, -Speed nature)
  - Scarf Max+ / Scarf Max (Choice Scarf ×1.5)
  - **Custom**: set your own Speed points, nature, and modifier
- **Trick Room mode**: flips the ladder so the slowest Pokémon come first, with an animated row-flip and sound effect (respects `prefers-reduced-motion`)
- **Search and filter**: find a Pokémon or type, and filter by Standard or Mega forms
